`fadeIn` 是渐现动画，影响 `opacity` 透明度属性。

## 开始使用

<img alt="fadeIn" src="https://gw.alipayobjects.com/mdn/rms_f5c722/afts/img/A*LTRRRL8JwfQAAAAAAAAAAABkARQnAQ" width="400" />

```ts
chart.options({
  type: 'interval',
  /* ... */
  animate: { enter: { type: 'fadeIn' } },
});
```
